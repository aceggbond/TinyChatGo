# HFS Go

HFS Go 是一款面向 Windows 的轻量、安全局域网文件分享与在线聊天工具。无需部署数据库或 Web 服务器，运行一个可执行文件，即可让同一局域网内的电脑、手机和平板通过浏览器访问。

## 主要功能

### 文件分享

- 分享任意文件或文件夹，不移动、不复制原始内容。
- Windows 后台支持文件和文件夹拖放添加。
- 支持多选批量移除、右键管理、重命名显示名称、复制磁盘路径和资源管理器定位。
- 浏览器支持目录浏览、文件搜索、多文件拖放上传和上传进度显示。
- 支持断点下载，以及图片、音视频、PDF 和文本在线预览。
- 没有可写分享目录时，可将上传文件保存到 Windows 临时目录；删除此类临时分享时会再次确认是否同时删除磁盘文件。
- 开启聊天时，文件功能集成在系统群顶部的折叠面板中；关闭聊天时，文件分享可独立显示。

### 在线聊天

- 浏览器与 Windows 后台通过 WebSocket/WSS 实时通信。
- 支持系统群、访客与管理员私信、访客之间私信。
- 管理员在浏览器用户列表中作为独立会话显示，管理员私信与系统群历史完全分离。
- 系统群始终置顶；有新私信的会话自动提前排列。
- 前端和后台均显示未读数量并闪烁提醒，打开会话后自动清除未读状态。
- 支持按 IP、姓名、中文全拼和拼音首字母即时搜索用户。
- 支持长文本、Enter 发送、常用表情、图片粘贴、图片/文件拖放发送。
- 聊天图片支持点击放大、上一张和下一张切换。
- 图片最大支持 100 MiB，普通文件最大支持 1 GiB；大附件通过流式上传保存，避免 Base64 占用过多内存。

### 用户与权限

- IP 地址是用户的唯一 ID，每个 IP 只保留一条用户记录。
- 首次使用聊天必须设置名称，显示形式为 `IP-名称`；用户和管理员都可以修改名称。
- 后台可查看 IP、连接端口、浏览器、系统版本和最近访问时间。
- 支持将指定 IP 加入或移出黑名单；黑名单会拒绝网页访问、上传、下载和聊天连接。
- 设置页可分别控制上传、下载、聊天、系统群、用户列表和用户私信。
- 未开启的功能不会在浏览器界面显示，避免出现无效区域。

### HTTP、HTTPS 与通知

- HTTP 与 HTTPS 可同时监听不同端口。
- 可自动生成局域网 HTTPS 证书，也可开启 HTTP 自动跳转 HTTPS。
- CA、服务端证书和私钥统一保存在 `hfs-go.db`，重新生成时直接覆盖数据库中的旧证书。
- 支持访问密码保护。
- 浏览器端支持新消息通知；Windows 服务端支持新访客和新消息右下角提醒。
- 浏览器已订阅提醒后不会重复显示订阅提示。

### Windows 后台

- 现代化三栏导航：聊天、文件管理、设置。
- 自动识别所有网卡地址，可选择实际监听和分享的 IP。
- 点击蓝色 HTTP/HTTPS 地址即可复制。
- 单实例运行：重复启动程序时会唤醒已运行窗口，不会启动第二个服务端。
- 点击窗口关闭按钮会最小化到托盘；使用 `Alt+F4` 会直接退出程序。
- “关于”页面支持检查 GitHub Releases 更新，并显示项目地址和作者打赏二维码。

## 数据保存

程序会在可执行文件所在目录创建以下数据：

| 路径 | 内容 |
| --- | --- |
| `hfs-go.db` | 配置、分享列表、用户名称、黑名单、聊天记录、访问记录和 HTTPS 证书 |
| `chat_files/` | 聊天图片和聊天文件，按日期建立子目录 |

聊天记录不会写入普通配置文件。删除 `hfs-go.db` 会重置持久化数据，程序下次启动时会自动创建新数据库。请不要将包含密码、用户信息或证书私钥的数据库分发给其他人。

后台设置页提供“清空聊天记录”和“清空用户信息”两个独立操作。清空聊天记录会同时删除数据库记录以及 `chat_files` 中对应的聊天附件。

## 使用方法

1. 从 [Releases](https://github.com/aceggbond/hfs-go/releases) 下载 `HFS-Go.exe`。
2. 运行程序，在“设置”中选择网卡地址和 HTTP/HTTPS 端口。
3. 按需开启上传、下载、聊天、用户列表、私信和通知功能。
4. 在“文件管理”中拖入需要分享的文件或文件夹。
5. 启动服务，点击蓝色访问地址复制并发送给局域网用户。

如果启用 HTTPS，可在设置页点击“生成/更新证书”。局域网自签名证书可能需要在访问设备上手动信任，或者由用户确认浏览器的证书提示。

## 权限组合

| 后台设置 | 浏览器显示 |
| --- | --- |
| 只开启上传或下载 | 仅显示文件区域 |
| 只开启聊天 | 显示用户列表与聊天区域 |
| 同时开启文件与聊天 | 文件面板折叠集成到系统群 |
| 关闭用户列表 | 不显示其他在线用户和用户私信入口 |
| 关闭用户私信 | 保留系统群，但用户之间和用户到管理员的私信入口不可用 |

## 源码构建

需要 Go 1.20 或更高版本：

```powershell
go test ./...
go build -buildvcs=false -ldflags "-H=windowsgui" -o HFS-Go.exe .
```
