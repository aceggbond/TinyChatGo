# HFS Go

用 Go 编写的 Windows 原生 HTTP 文件服务器，交互参考 Rejetto HFS 2.x，但不包含旧版的宏/模板执行引擎。

## 功能

- 原生 Windows GUI，文件和文件夹可直接拖入窗口
- 虚拟文件系统：分享项目不会移动或复制原文件
- 添加、移除、虚拟重命名，退出时自动保存分享列表
- HTTP 目录浏览、Unicode 文件名、大文件流式传输、Range 断点续传
- 可选访问密码（浏览器 Basic Auth）
- 上传和下载权限可独立开关；支持网页多文件上传
- 网页管理权限独立开关：新建目录、删除文件或目录
- 网页管理支持安全重命名，目标重名时拒绝覆盖
- 当前目录/根分享搜索，文件夹可流式打包为 TAR 下载
- 同名上传自动编号，避免覆盖已有文件
- 图片、音视频、PDF 和纯文本可直接在浏览器预览
- 自动识别局域网 IPv4 地址，并可一键复制分享 URL
- 最小化到系统托盘，双击托盘图标恢复窗口
- 启停采用异步状态控制，启动前检查端口占用并防止连续点击卡死
- 表格化访问日志：时间、客户端、方法、路径、状态和耗时，可一键清空
- 实时访问日志，随机局域网客户端也可通过本机 IP 访问
- 仅使用 Go 标准库，无第三方运行时

## 构建与运行

```powershell
go build -ldflags "-H=windowsgui" -o HFS-Go.exe .
./HFS-Go.exe
```

开发调试时可以直接执行 `go run .`。默认监听 `1122`；Windows 首次允许局域网访问时，可能会弹出防火墙授权提示。

> 安全提示：访问密码通过 HTTP Basic Auth 工作。不要把 HTTP 端口直接暴露到公网；公网使用时应在可信反向代理后配置 HTTPS。上传默认关闭，建议只对可信目录和可信用户开启。
